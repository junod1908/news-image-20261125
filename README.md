Sum up 25 November 2026's world news in one image — a one-page broadsheet, "The World in One Day": a serif masthead naming the day, three illustrated lead stories (US tariffs on 14 economies, Shenzhou-24 carrying the first Pakistani astronaut, Kospi down 6.2%), a numbered world map with a pin for every story, a UTC timeline strip, and a 48-item numbered index across 8 regions. Every story was date-audited to Wednesday 25 November 2026: one candidate backed only by rival posters was dropped and replaced with a fully verified one, three borderline cases are flagged on the poster's face, and a DATE CHECK box names the stories left out because they happened earlier (the Huawei verdict, the Riyadh tower drone strike, the UN's 47,000-women report, and more). The program draws the whole page itself with the Python standard library only (no network): every word is set in anti-aliased type from a DejaVu glyph atlas shipped in the repository, and the map is drawn from a land mask in the code.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
